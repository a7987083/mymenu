Date: 2026-09-14

## Status

v0.5.6.2 is the official sealed runtime-patch-menu baseline and the recommended device build.

It supersedes v0.5.6 as the recommended injected-menu runtime build while preserving the v0.5.6 Protection V2 / Full Deferred Bootstrap architecture and generated-binary compatibility.

## Device acceptance

The original-binary injection path was validated on device. The menu is injected into an original, unmodified application binary rather than a Builder-generated target.

The v0.5.6.1 diagnostic build exposed a dyld add-image replay / Static Dispatch refresh storm. v0.5.6.2 suppresses registration-time replay, coalesces real image-add bursts, and coalesces Static Dispatch refresh requests. Device validation showed first activation reduced from the previous tens-of-seconds stall to roughly 0.69 seconds, with no recurrence of the prior refresh storm during the acceptance run.

An original binary having no generated `__ZNDATA/__zndata` metadata is an expected supported state. Static Dispatch may report no generated logical/physical patches in this mode without treating it as an error.

## Release cleanup

The temporary persistent activation-trace logger used during v0.5.6.1/v0.5.6.2 diagnosis is not shipped in the sealed build:

- `ZNActivationTrace.mm` is removed from the build and repository branch.
- Activation trace calls are compile-time disabled through `ZNActivationTrace.h`.
- No `Documents/ZonoPatch-v0.5.6.2.log` writer remains.
- The final binary was independently checked and does not contain the `ZonoPatch-v0.5.6.2.log` filename or the activation-trace header string.

The existing in-memory/runtime diagnostic logger and failure-only console diagnostics are intentionally retained. They do not create the temporary activation log file and remain useful for menu diagnostics and future fault isolation.

## Preserved invariants

- Full Deferred Bootstrap remains intact: before the first menu-icon click, the feature/runtime initialization chain is not started.
- Exactly one load-time constructor remains: the cold floating launcher.
- No compiled Objective-C `+load` methods are introduced.
- Protection V2 remains enabled.
- Static RVA Protection V1 remains enabled.
- ZNF1/static metadata format remains compatible.
- Shared-Site owner-stack behavior remains unchanged.
- Runtime executable-page mutation is not introduced; generated Static Dispatch still switches RW `selectedTarget` only.
- Stock iOS / no-JIT architecture remains unchanged.
