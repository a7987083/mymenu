## Final scope

- Keep v0.5.5 Full Deferred Bootstrap behavior: before the first icon tap, only the icon/bootstrap shell is active; Patch Runtime and menu subsystems remain deferred.
- Protection V2 uses build-time polymorphic payload layout. OFF/ON ARM64 variants are fragmented into per-instruction slots and connected by explicit branch chains.
- Runtime continues to switch only the RW `selectedTarget`; executable pages are not rewritten after launch.
- Static Dispatch ABI remains compatible: 64-byte header, 128-byte entries.
- Header protection flags on V2 outputs combine ZNF1, Static RVA Protection V1, and Payload Protection V2 (`0x7`).
- Shared-site canonical/owner-stack behavior remains part of the supported model.
- Generated binaries continue through the explicit pipeline and final ad-hoc CodeDirectory rebuild; whole IPA resign is still required before installation.

## Security scope

Protection V2 is a static-analysis cost layer, not a secrecy guarantee. A determined local analyst can still recover executable control flow. This release does not add further menu anti-reversing work; v0.5.6 is sealed as the stable rollback/baseline for future functional development.
